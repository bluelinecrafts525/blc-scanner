Chipply PDFs (including multi-order batches) are read directly — each order is split out for review and defaults to Paid. Invoice-software screenshots go through OCR: Client → customer, Invoice Date → order date (+10 days due), Item → description, Qty from its own box — these default to Unpaid.

🏷 Bulk print labels

For batches that don't need a full order record — just print labels. Paste rows (tab or comma separated, e.g. copied straight from Excel/Sheets) or upload a CSV. A header row is fine, it's detected and skipped.

CSV/paste column order (required):
1. Customer name  →  2. Organization/group  →  3. Piece count  →  4. Shipping method  →  5. Order/Invoice #  →  6. Player name (optional — for org batches with individually packed orders)
